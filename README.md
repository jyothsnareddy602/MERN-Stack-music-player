🎶 MERN Stack Music Player
A full-stack music streaming application developed using the MERN Stack (MongoDB, Express.js, React.js, Node.js) during my internship at Web Stack Academy.

This project showcases seamless frontend–backend integration, secure authentication, playlist management, and real-time audio streaming — designed to replicate real-world music player functionality.

✨ Key Highlights
🔐 User Authentication with JWT (Login/Signup)

🎵 Music Controls: Play, Pause, Next, Previous

📊 Interactive Progress Bar with seek functionality

📂 Playlist Management: Create, edit, and organize playlists

📤 Song Upload & Streaming with backend integration

💻 Responsive UI built with modern design principles

🔗 RESTful APIs for smooth client-server communication

🛡️ Secure Backend powered by Node.js  & Express

🗄️ MongoDB Database with Mongoose ORM

⚙️ Installation & Setup
Clone the repository

git clone https://github.com/jyothsnareddy602/MERN-Stack-music-player.git

Backend Setup

cd backend
npm install
npm start
Frontend Setup

cd frontend
npm install
npm start
Environment Variables  
Create a .env file inside backend/ with:

Code
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
PORT=5000
